## BugSnap v2.0.0

BugSnap helps nontechnical users record what happened on a website and share one evidence package with a developer or support team.

### User workflow

1. Start recording.
2. Mark the moment something goes wrong.
3. Finish and export a ZIP containing a readable timeline, structured data, and available screenshots.

The current interface is in Simplified Chinese. The repository README is in English.

### Included

- Automatic user-action and common page-feedback records.
- Cross-page recording with local persistence and manual stopping.
- Fetch/XHR request summaries and JavaScript diagnostics.
- Optional screenshots at the start, at problem markers, and at the end.
- Advanced element selection, annotation, manual reports, and screenshot comparison.

### Install

Download **BugSnap-v2.0.0.zip** below and extract it. Open `chrome://extensions`, enable Developer mode, choose Load unpacked, and select the extracted `bugsnap` directory. Chrome 116 or newer is required.

This is an unpacked extension package, not a Chrome Web Store installation. No dependency installation or backend is needed.

`SHA256SUMS` contains the SHA-256 checksum of the installation ZIP. GitHub's automatically generated source archives are separate from this ready-to-load package.

### Data and permissions

Recordings stay on the device until the user exports and shares them. Raw input text is excluded from action events, and common sensitive text is filtered on a best-effort basis. Screenshots and page messages can still contain personal information. Optional website access is requested when recording begins.

### Validation and limitations

59 logical tests, nine action/privacy browser checks, and six continuous-session browser checks passed during development. Some extension APIs are represented by test adapters; the v2 permission flow and behavior on actual target websites still require installed-extension acceptance testing.

BugSnap is an evidence timeline rather than a full session-replay engine. Very early events, restricted pages, iframe/Worker internals, and some custom UI feedback may not be captured. See the README for details.
